# Social Media Platform

A fully functional and responsive social media platform built using HTML5, CSS3, and JavaScript. This platform enables dynamic user interactions such as post creation, editing, liking, and deletion while ensuring cross-browser compatibility and mobile-first design principles.

## Features

- **User Authentication**: Secure login and registration with custom form validation and client-side JavaScript logic.
- **Post Management**: Users can create, edit, like, and delete posts.
- **Responsive Design**: Ensures a seamless experience on mobile and desktop devices.
- **SEO & Accessibility**: Uses semantic HTML5 tags to improve search engine visibility and accessibility.
- **Performance Optimization**: Debugged and tested using Chrome DevTools for enhanced frontend performance.

## Technologies Used

- **HTML5** for structuring web pages
- **CSS3** for styling and responsiveness
- **JavaScript** for dynamic interactions and form validation

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/social-media-platform.git
   ```
2. Navigate to the project directory:
   ```bash
   cd social-media-platform
   ```
3. Open `index.html` in your browser.

## Usage

- Sign up or log in using the authentication form.
- Create new posts and interact with other users by liking or commenting.
